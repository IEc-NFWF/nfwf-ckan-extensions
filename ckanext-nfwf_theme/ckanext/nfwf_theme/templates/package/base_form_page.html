{{ _('What are datasets?') }}

{% trans %} A dataset is a collection of data resources (such as files) and descriptive information available from a single webpage. Datasets are what users see when searching for data.

The Coastal Resilience Open Data Platform is built to allow grantees the flexibility to define datasets for their grants at a level suited to how their data are collected or organized. Generally speaking, a good dataset provides a collection of resources around a theme within your grant. Data are best structured around themes that are easily delineated and searchable.

Themes or collections can evolve over time by adding resources to the dataset. For instance, if you have selected to define a dataset around a particular geography, you can add resources to that dataset as you collect more data at that location. In addition, if you are collecting data across multiple years, you can create your initial dataset, add resources over time, and tag the additional years (or other fields) in the metadata. {% endtrans %}
